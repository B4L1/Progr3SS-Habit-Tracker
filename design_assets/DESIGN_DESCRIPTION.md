# Progr3SS - Habit Planner & Tracker Design Description

## Splash Screen
*   Shows a startup animation
*   Performs a login check and auto-logs in if authenticated
*   Redirects to main or login screen

## Register Screen
*   User enters an username, an email, and a password, followed by its confirmation
*   If passwords do not match, the text fields show a red border and the hint text provides details
*   For successful registration, the user is sent to the home screen
*   The user can also choose to authenticate with their Google account

## Reset Password Screen
*   User enters an email and waits for a message
*   New password is generated and sent through email

## Login Screen
*   User enters email and password
*   Credentials are validated and sent to backend
*   Successful login navigates to main app
*   Includes Google login and "Forgot password" option

## Home Screen
*   See todayʼs schedule
*   Sorted by time of day
*   View status : completed/not completed
*   Go to Add Schedule Screen

## Create Schedule Screen
*   Choose a defined habit or create a new one
*   Set a start time
*   Select a repeat pattern
*   Define a goal duration
*   Add partners - optional
*   Create to save or Cancel to discard

## Add Habit
*   Habit Name
*   Description - a short motivation or explanation behind the habit
*   Set a goal
*   Select category - choose an icon to define the habitʼs category

## Add Progress
*   Update your progress
*   Can add optional notes
*   Counts towards the completion of a schedule

## Schedule Details Screen
*   Details of the habit
*   Progress bar
*   Notes about habits
*   Recent activities - historical data

## Edit Schedule Screen
*   Edit the Start Time and End Time
*   Duration - modify the total time
*   Set a status - Planned, Skipped or Completed
*   Partner - add or remove participants
*   Notes - Edit or update notes

## Edit Notes
*   Edit notes directly from Schedule Details Screen
*   Go to edit mode
*   Save the note
*   Easier to note

## Delete Schedule
*   Options menu - delete button
*   PopUp window - are you sure?

## Profile Screen
*   Summary of profile data
*   Check your habits and progress
*   Can add new habits
*   Can logout with confirmation dialog

## Edit Profile Screen
*   Can access it from Edit Profile Screen
*   Set a new username
*   See your email address and profile photo

## AI Assistant Screen
*   OpenAI API Integration
*   Can ask for habit suggestions and health tips
*   Can accept or decline given schedule recommendations
